# Splunk Scope — UI Audit (Screen-Share First)

**Date:** 2026-06-03  
**Version:** 2.0.0  
**Auditor context:** Live SE workshop on MacBook **14"** (also validated against Air 13" safe area), **Zoom 1080p** share, **dark mode** (primary; light mode spot-checked against archived pass).  
**References:** [`PRODUCT_PRINCIPLES.md`](./PRODUCT_PRINCIPLES.md) §7 (executive-ready UX), [`archive/UI_QA_REPORT.md`](./archive/UI_QA_REPORT.md) (2026-06-01 baseline).

**Viewport method:** Code + layout review at **1440×900** and **1280×720** with **52px** icon sidebar (~1388×898 and ~1228×718 content). Playwright e2e matrix (F01–F10) used to confirm no ErrorBoundary regressions; visual scoring is presenter-centric, not automated pixel diff.

**Scoring (1–5, higher is better):**

| Dimension | 5 | 1 |
|-----------|---|---|
| **Legibility** | Hero metrics and labels readable at arm's length on a 1080p Zoom tile | Body copy illegible without browser zoom |
| **Cognitive load** | One story per viewport band; progressive disclosure | Multiple competing panels; presenter must explain chrome |
| **Decisions obvious** | Primary next step visible without hover | Next action buried or ambiguous |
| **Scroll economy** | Above-the-fold tells the story; scroll is optional | Deep scroll required before any decision |

---

## Executive summary

Splunk Scope is **strongest on Home, Analysis hero, and Report Overview** — large type and clear CTAs match §7 “calm, skimmable, decisive.” Pain concentrates on **Sources (drawer split-attention), Review (8-column table), Coverage (6px badges + two-column at 720p height), and Paths (four narrow columns + hidden tab scroll at 1280)**. Icon-only sidebar is the **#1 presenter tax** on every workflow step after Home.

**Screen-share recommendation:** Stay at **110% browser zoom** on 1280×720 shares; pre-load an example scenario; narrate sidebar step on every transition until labels ship.

**Top 3 fixes**
